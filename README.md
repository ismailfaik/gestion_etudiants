# Gestion des étudiants

## Description
Application Python permettant de calculer la moyenne et le résultat des étudiants.

## Technologies utilisées
- Python 3
- Pytest
- Git
- GitHub

## Installation
Cloner le dépôt :
~~~bash
git clone [https://github.com/ismailfaik/gestion_etudiants.git](https://github.com/ismailfaik/gestion_etudiants.git)
~~~
Accéder au projet :
~~~bash
cd gestion_etudiants
~~~
Créer un environnement virtuel :
~~~bash
python -m venv venv
~~~
Installer les dépendances :
~~~bash
pip install -r requirements.txt
~~~

## Exécution
~~~bash
python src/main.py
~~~

## Tests
~~~bash
python -m pytest -v
~~~
